# Отчёт по проекту MIS Dash

В этой директории находятся исходники Typst для отчёта по стажировке MIS Dash.
Все неизвестные персональные данные помечены `TODO` в файле `project.typ`: перед
сдачей их нужно заменить на фактические сведения.

## Сборка без интернета

Используется только стандартная библиотека Typst, без загружаемых пакетов.
Из корня репозитория выполните:

```bash
mkdir -p docs/report/build
typst compile --root . docs/report/report.typ docs/report/build/report.pdf
```

Для автоматической пересборки отчёта во время редактирования:

```bash
typst watch --root . docs/report/report.typ docs/report/build/report.pdf
```

Собранный PDF не попадает в Git. Перед сдачей его нужно открыть и проверить
титульную страницу, содержание, переносы таблиц и список источников.

## Структура

- `project.typ` — общие метаданные автора и проекта;
- `styles.typ` — стили отчёта и титульной страницы;
- `report.typ` — точка входа отчёта;
- `sections/` — самостоятельные разделы отчёта;
- `diagrams/` — исходники и отрендеренные архитектурные диаграммы;
- `references.bib` — библиографические источники.

## Что заполнить вручную

1. Метаданные в `project.typ`.
2. Фактическое распределение ролей и ФИО второго участника.
3. Сведения для раздела о рекомендательном письме и собеседовании.
4. Фактические промежуточные результаты и скриншоты интерфейса.
5. Требования образовательной организации к оформлению и объёму.
