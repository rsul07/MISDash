# Архитектурные диаграммы MIS Dash

Диаграммы хранятся рядом с отчётом, но могут использоваться и в презентации.
Редактируемые Mermaid-исходники находятся в `src/`, готовые SVG и PNG — в
`rendered/`.

## Состав

- `02-c4-containers` — контейнеры системы и их зависимости;
- `03-parser-components` — внутренняя структура parser;
- `04-processing-sequence` — последовательность обработки загруженного файла.

## Редактирование и сборка

Чтобы изменить подпись или элемент, отредактируйте соответствующий `.mmd` в
`src/`, затем из корня репозитория выполните:

```bash
docs/report/diagrams/render.sh 02-c4-containers
```

Без аргумента скрипт пересобирает все диаграммы. После сборки нужно проверить
SVG или PNG визуально и добавить в коммит и исходник, и оба результата рендера.
