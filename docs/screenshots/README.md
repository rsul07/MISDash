# Скриншоты MIS Dash

Эта директория содержит презентационные кадры интерфейса только с
синтетическими данными.

Фиксированный сценарий:

- desktop browser window: `1600×900` (`1600×757` в PNG);
- mobile browser window: `390×844` (`390×701` в PNG);
- масштаб браузера 100%;
- источник: встроенный generator;
- `seed=7`;
- глубина истории: 3 года;
- режим `light=true`;
- светлая тема из `.streamlit/config.toml`.

Файлы:

- `dashboard-overview.png` — профиль пациента и первый клинический сигнал;
- `dashboard-metrics.png` — последние значения и 90-дневный график АД;
- `dashboard-visits.png` — поиск и таблица врачебных приёмов.
- `dashboard-mobile-overview.png` — паспорт и красный флаг на телефоне;
- `dashboard-mobile-visits.png` — мобильные карточки приёмов.
- `documentation/` — расширенные кадры `1440×1100`, где виден дополнительный
  клинический контекст ниже первого экрана.

Для воспроизводимой пересъёмки запустите приложение и capture-скрипт:

```bash
streamlit run src/app/main.py
python docs/screenshots/capture.py
```

Скрипт использует локальные `chromedriver` и Chromium, не обращается к Gemini
и перезаписывает только перечисленные PNG.

Перед заменой изображения проверьте имя и показатели пациента по созданной
синтетической выгрузке. Реальные медицинские данные, API-ключи, адресная строка
с чувствительными параметрами и персональные уведомления в кадр попадать не
должны.
