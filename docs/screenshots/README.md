# Скриншоты MIS Dash

Эта директория содержит презентационные кадры интерфейса только с
синтетическими данными.

Фиксированный сценарий:

- viewport: `1600×900`, масштаб браузера 100%;
- источник: встроенный generator;
- `seed=7`;
- глубина истории: 3 года;
- режим `light=true`;
- светлая тема из `.streamlit/config.toml`.

Файлы:

- `dashboard-overview.png` — профиль пациента и первый клинический сигнал;
- `dashboard-metrics.png` — последние значения и 90-дневный график АД;
- `dashboard-visits.png` — поиск и таблица врачебных приёмов.

Перед заменой изображения проверьте имя и показатели пациента по созданной
синтетической выгрузке. Реальные медицинские данные, API-ключи, адресная строка
с чувствительными параметрами и персональные уведомления в кадр попадать не
должны.
